# GEM Cardoso — protótipo

Caderno de estudos responsivo com rascunho e fichas salvos no navegador. Funciona offline depois da primeira abertura online e preparação do cache.

Publicação: Settings > Pages > Deploy from a branch > main > / (root).

Os registros são locais, exclusivos de cada navegador e endereço. Não há envio ao Google Forms nem sincronização entre aparelhos. Use Exportar fichas para fazer uma cópia.
